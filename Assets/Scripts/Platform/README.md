# Platform

Обёртки над PluginYG2 для требований Яндекс Игр. Игра зовёт их, не зная про плагин:
без плагина или модуля код компилируется и ведёт себя разумно.

## PlatformGameplay — Gameplay API
Обязательно для модерации. Все переходы состояния игры обычно сходятся в одном месте
(`SetState` и т.п.) — туда и ставятся вызовы:

```csharp
switch (state)
{
    case GameState.Playing: PlatformGameplay.Start(); break;
    default:                PlatformGameplay.Stop();  break; // меню, магазин, результат
}
```

Нюансы:
- Без явного `Start` разметка не уходит ни разу: штатные stop/start плагина вокруг
  рекламы и потери фокуса возобновляют только то, что игра начала сама.
- Во время рекламы и без фокуса старт не отправляется, но запоминается и досылается,
  когда плагин снимает паузу. Без этого уровень, запущенный под interstitial,
  остался бы без разметки.
- Повторные вызовы безопасны — плагин отсекает их сам. В кликере без чётких
  «уровней» можно звать `Start` на каждое игровое событие.

## RewardedAds — реклама за награду
```csharp
RewardedAds.Show("hint", () => GiveHint());
```
- Модуль Rewarded Adv подхватывается по дефайну `RewardedAdv_yg`.
- Без модуля награда выдаётся сразу — механику можно делать и проверять до
  подключения рекламы. `IsRealAdAvailable` скажет, настоящая ли реклама (например,
  чтобы прятать значок «видео» на кнопке).
