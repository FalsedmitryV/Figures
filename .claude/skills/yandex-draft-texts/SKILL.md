# Тексты черновика Яндекс Игр

Результат — файл `CodeDocs/YandexDraft.md`: по разделу на каждый язык, каждое поле в
отдельном блоке ```text, чтобы копировать в консоль как есть. Лимиты проверяются
скриптом, а не на глаз.

## Поля и лимиты

| Поле | Лимит | Обяз. | Что туда писать |
|---|---|---|---|
| Название | 50 | да | 2–3 слова, понятно и запоминается. Ровно как в самой игре и на промо для этого языка (п. 5.1.3). Без слова «игра» (6.5). Уникально в каталоге (5.12). |
| Описание для SEO | 160 | нет | Сниппет под заголовком в поисковиках. Жанр + суть геймплея/сеттинга + крючок (режимы, рекорды). Живой текст, не список ключевиков. |
| Об игре | 1000 | да | Страница игры. Сюжетная завязка → суть геймплея → механики и фишки → режимы → список «Особенности:». |
| Короткое описание | 70 | нет | Слоган/ключевая фишка для подборок каталога. С заглавной буквы. Не повторять название, без слова «бесплатная» и фразы «на русском», не в кавычках целиком. |
| Как играть | 1000 | да | Управление по платформам (ПК/телефон), правила, бонусы, очки. Блоки «Управление:», «Правила:», «Бонусы:». |
| Ключевые слова | 100 | нет | Через запятую без пробелов: жанр, тип геймплея, фишки, конкуренты, известные игры в похожем стиле. Поле общее для всех языков — писать на основном языке (обычно ru). |

Цель по длине: 85–99 % лимита у «Об игре», «Как играть», SEO; не превышать никогда.
Переводы обычно длиннее русского (de, tr) — ужимать перевод, а не обрезать на полуслове.

## Правила модерации (раздел 5 и 8 требований)

- Только то, что реально есть в игре (8.2.2). Ни одной механики «на вырост».
- Одинаковый текст в разных полях запрещён (5.11) — SEO, короткое и «Об игре»
  формулируются по-разному.
- Нет ссылок, доменов, названий других платформ/сторов, призывов перейти куда-то (8.4.2, 8.4.4).
- Нет мата ни на одном языке (8.2.4); орфография и пунктуация языка (8.2.1).
- Нет заполнения лимита повторами символов (5.11).
- Не просить оценок/отзывов, не обещать награды за них.
- Названия бонусов, врагов, режимов — такие же, как в UI игры на этом языке.

## Порядок работы

1. **Собрать факты из проекта, а не придумывать.**
   - `Assets/Resources/Lang/*.csv` — названия игры, бонусов, режимов, подсказки обучения;
     список csv = список языков. Термины брать отсюда дословно.
   - Клавиши — ассет ввода (`*.inputactions`, конфиг клавиш), тач-управление — скрипты ввода.
   - Числа (очки, число уровней, длительности, заряды) — из конфигов/ScriptableObject
     и `Scripts/Data`, `Scripts/Core`. Ассеты `.asset` читаются как YAML.
   - Облачные сохранения, лидерборд, реклама — модуль `Scripts/Platform`.
   - Если факт не найден в проекте (сюжет, сеттинг, «на что похожа») — спросить
     пользователя одним списком вопросов, не выдумывать.
2. **Если `CodeDocs/YandexDraft.md` уже есть** — прочитать и править его, сохраняя
   формулировки, которые пользователь не просил менять.
3. **Написать ru** (основной язык), затем переводы на остальные языки из `Lang/`.
   Перевод — адаптация: живой текст на языке, игровые термины из соответствующего csv.
4. **Проверить длины**:
   ```bash
   python .claude/skills/yandex-draft-texts/check_lengths.py CodeDocs/YandexDraft.md
   ```
   Скрипт считает символы как консоль (перенос строки = 1 символ) и печатает
   `ПРЕВЫШЕН` / `пусто` / `повтор`. Править, пока всё не будет `ok`.
5. В ответе — короткая таблица длин по языкам и список вопросов/допущений, если были.

## Формат файла

Заголовки строго такие — по ним работает скрипт проверки:

````markdown
# Черновик Яндекс Игр

## ru

### Название
```text
...
```

### Описание для SEO
```text
...
```

### Об игре
```text
...
```

### Короткое описание
```text
...
```

### Как играть
```text
...
```

### Ключевые слова
```text
...
```

## en
...
````

«Ключевые слова» — только в разделе основного языка. Маркеры списков — `•`, как
в консоли; без markdown-разметки внутри блоков (консоль её не рендерит).

## Скелет «Об игре»

```
<Завязка: кто, что случилось, 1–2 предложения>

«<Название>» — <жанр>: <суть в одном предложении>. <Главная особенность управления.>

<Абзац механик: как устроены враги/препятствия, что меняется по ходу, уровни и режимы.>

<Абзац бонусов/прогрессии.>

Особенности:
• ...
• ...
```

## Скелет «Как играть»

```
Управление:
• ПК: ...
• Телефон: ...

Правила:
• Цель — ...
• ...

Бонусы:
• ...
• Очки: ...
```
